# 08 · 理论核验（n3~n100）

> 本文件是理论篇 D1–D3 条件在真实环境状态上的数值核验口径与结果。
> 核验产物独立归档在 `artifacts/theory_audit/`（三级文档：`说明.md`）。

---

## 一、目的

理论篇给出 D1（连续块决策局部/秩一）、D2（关联块块对角 + 秩 ≤ n + 范数受控 E）、
D3（联合谱收敛）与 A6（关联压缩）。本核验回答一个问题：

**这些条件在 n3~n100 的真实环境状态上是否成立、余量多大。**

核验不训练新策略，不改变任何训练/评估口径；只读环境状态，做数值雅可比与谱估计。

---

## 二、方法

### 2.1 状态来源

- 环境：`UAVEnvV3`，`use_physics=False`（核验只依赖关联/负载/场，不依赖 MuJoCo 动力学）。
- 规模：n3 / n12 / n30 / n60 / n100；`layout_n=max(12,n)`。
- 场景：flow / burst。
- 口径：`PF_CHANNEL=umi`、`PF_SHADOW_DB=6`、`PF_DXY_MAX=0.5`、`PF_REAL_OBS=0`。
- 执行器：纯场 η≡1，动作 `clip(Λ⊙(X*−X), ±U)`，`Λ=diag(0.2,0.2,1,1,1)`。
- 推进 700 步到 pre 窗口，取快照；flow/burst 同起点同推进。

### 2.2 D1：连续块决策局部

对 `b* = c/u*`（总量超 B 时按比例缩）做数值雅可比：

```
J_b[i,j] = ∂b*_i/∂c_j
```

报告：奇异值比 `σ₂/σ₁`（秩一残差）、非对角能量占比、当前运行区
（锚定/预算/回传）。

### 2.3 D2：关联块低秩结构

对关联一步映射 `T_a(a)` 做 matrix-free Jacobian-vector product：

```
Jv ≈ (T_a(a+εv) − T_a(a))/ε
```

并按理论式显式拆三部分：

```
D_col = (1−1/τ_u)I + (1/τ_u)·α·S·(∂r/∂a)     逐用户块对角
L     = (1/τ_u)·κ·S·G_row                     rank ≤ n
E     = Jv − D_col v − L v                    速率反馈项
```

报告：`D_col/L/E` 的能量占比、`L` 的第 n 与第 n+1 个奇异值之比
（谱断崖）、`E/L` 范数比、`J` 的谱范数下界与 ARPACK 谱半径。

### 2.4 D3：联合谱收敛

按 D3 的加权范数充分条件：

```
ρ_J = max(ρ_a + w·L_Xa, ρ_X)
```

- `ρ_a`：`∂T_a/∂a` 的谱半径，优先用 SciPy/ARPACK `eigs` 直接求特征值
  （非正规矩阵的幂迭代会被瞬态增长污染，只作 fallback）；
- `ρ_X = max_k |1−λ_k η_k|`，η≡1；
- `L_Xa`：连续目标（b/π）对关联 `a` 的敏感度，有限差分估计；
  位置质心在 argmax 切换处是离散跳变，单列 `partition_switch_rate`，
  不计入连续 `L_Xa`（由定理的 δ_part 项处理）；
- 病态扰动（`R_avail < 1` 或 `u > 10`）单列 `pathological_rate`，不混入中位数。

### 2.5 辅助量

- A6：`L_a = ‖∂T_a/∂a‖₂`，判据 `L_a < 1`；
- 负载等式：`max_i u_i − min_i u_i`、`std(u)`；
- 均值场残差：`std(g)/mean(g)`，`g_i = R_avail_i/(ρ_i+ε)`；
- 污染标记：`n_dead = #{u>5}`、`u_mean`，用于剔除死机区样本。

## 三、结果（n3~n100，30 job，60 行）

核验输出：`artifacts/theory_audit/out/theory_audit_n3_n100.csv`（本地生成，不入库）。
5 规模 × 2 场景 × 3 种子 × 2 快照（700/1500 步）。

### 3.1 D1：连续块秩一结构

- 60/60 状态满足“标量主项 + 秩一耦合”的结构：`d1_offdiag` 中位数 0.134，
  范围 2.3e-11–0.708。
- 47/60 状态 `d1_sigma_ratio < 1e-3`；其余 13 个锚定区状态的残差已低于
  数值地板（`d1_offdiag ≤ 1e-10`），`d1_sigma_ratio` 是零残差的噪声比值，
  按 0 读。
- 结论：D1 在 n3~n100 全部状态成立，无实质失败。

### 3.2 D2：关联块分解

| 量 | 中位数 | 范围 | 读法 |
|---|---:|---:|---|
| `d2_dcol_energy` | 0.955 | 0.691–1.024 | D_col 占主体 |
| `d2_L_energy` | 3.4e-4 | 1.0e-5–1.2e-3 | L 能量小 |
| `d2_E_energy` | 0.318 | 0.068–0.717 | E 有界 |
| `d2_E_over_L` | 617 | 124–72650 | E 大于 L，但未超 J |
| `d2_gap_L` | 1.49 | 1.005–2.085 | L 的秩 n 断崖 |
| `d2_L_rank` | n | — | 解析秩上界 |

- 结论：`D_col` 块对角占主体、`L` 呈秩 ≤ n 的谱断崖、`E` 有界；D2 的
  结构成立。`E` 不是小量（中位 0.32），D2 的“范数受控”成立，但不能忽略。

### 3.3 D3 / A6：纯场硬分配边界

| 量 | 中位数 | 范围 |
|---|---:|---:|
| `a_max` | 1.000000 | 0.99999981–0.9999999997 |
| `a_entropy` | 0.159 | 0.00047–0.313 |
| `rho_min` | 58.1 | 31.3–374 |
| `R_avail_min` | 65.7 | 35.8–453 |
| `La_probe` | 8.13 | 3.05–122.9 |
| `rho_a`（ARPACK） | 388 | 45.4–1838 |
| `L_Xa_median` | 1.36e6 | 2.66e4–3.57e6 |
| `rho_J` | 1.36e6 | 2.67e4–3.57e6 |
| `u_mean` | 0.881 | 0.810–0.936 |
| `n_dead` | 0 | 0 |

- 60/60 状态的关联饱和到 `a_max≈1`（硬分配边界）；A6/D3 的充分条件
  **0/60 成立**（`La_probe<1`、`rho_a<1`、`rho_J<1` 均无）。
- `rho_min`/`R_avail_min` 保持数十到数百，`u_mean≈0.88`、`n_dead=0`：
  资源没有塌缩；失效来自 softmax 饱和后的 `1/D` 导数（`D` 接近噪声底），
  不是死机或资源耗尽。
- 读法：A6/D3 是充分条件；纯场 η≡1 的轨迹落在其适用区之外。该结果
  不构成发散证据（经验评估的 22 格 21 赢 1 输、零死机仍成立），但说明
  “纯场硬分配状态”不能用来宣称 D3 已被验证。学习执行器/软关联状态是否
  落在 A6 适用区，属于下一层核验对象。

### 3.4 辅助量

- `load_gap` 中位 0.125（0.0086–0.219）；`meanfield_residual` 中位 0.0335
  （0.0045–0.0469）；`n_dead` 全 0。

## 四、判读口径

| 量 | 支持理论的条件 | 读法 |
|---|---|---|
| `d1_sigma_ratio` | 接近 0 | 减掉标量主项后秩一结构成立 |
| `d1_offdiag` | 有界 | 秩一耦合项相对 J 的能量 |
| `d2_dcol_energy` | 占主体 | 逐用户块对角部分 |
| `d2_L_energy` + `d2_gap_L` | `gap_L` 明显 >1 | 行局部项秩 ≤ n 的谱断崖 |
| `d2_E_over_L` | 有界、不随 n 爆炸 | 速率反馈项范数受控 |
| `La_probe` | 下界；>1 即证伪 A6 | 关联谱范数下界 |
| `rho_a` | < 1（适用状态下） | 关联块谱半径（幂迭代） |
| `rho_J` | < 1 | D3 联合压缩充分条件 |
| `rho_min` | 不低于理论下界 | A6/β 有界前提 |
| `L_Xa_median` | 有界 | 连续目标（b/π）对关联的敏感度 |
| `partition_switch_rate` | 单列 | 位置质心离散切换率（由 δ_part 处理） |
| `load_gap` | 接近 0 | 负载等式 |
| `meanfield_residual` | 随 n 下降 | 均值场集中 |

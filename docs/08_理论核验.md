# 08 · 理论核验（n3~n100）

> 本文件是理论篇 D1–D3 条件在真实环境状态上的数值核验口径与结果。
> 核验产物独立归档在 `artifacts/theory_audit/`（三级文档：`说明.md`）。

---

## 一、目的

理论篇给出 D1（连续块决策局部/秩一）、D2（关联块块对角 + 秩 ≤ n + 范数受控 E）、
D3（联合谱收敛）与 A6（关联压缩）。本核验回答一个问题：

**这些条件在 n3~n100 的真实环境状态上是否成立、余量多大。**

核验不训练新策略，不改变任何训练/评估口径；只读环境状态，做数值雅可比与谱估计。

---

## 二、方法

### 2.1 状态来源

- 环境：`UAVEnvV3`，`use_physics=False`（核验只依赖关联/负载/场，不依赖 MuJoCo 动力学）。
- 规模：n3 / n12 / n30 / n60 / n100；`layout_n=max(12,n)`。
- 场景：flow / burst。
- 口径：`PF_CHANNEL=umi`、`PF_SHADOW_DB=6`、`PF_DXY_MAX=0.5`、`PF_REAL_OBS=0`。
- 执行器：纯场 η≡1，动作 `clip(Λ⊙(X*−X), ±U)`，`Λ=diag(0.2,0.2,1,1,1)`。
- 推进 700 步到 pre 窗口，取快照；flow/burst 同起点同推进。

### 2.2 D1：连续块决策局部

对 `b* = c/u*`（总量超 B 时按比例缩）做数值雅可比：

```
J_b[i,j] = ∂b*_i/∂c_j
```

报告：奇异值比 `σ₂/σ₁`（秩一残差）、非对角能量占比、当前运行区
（锚定/预算/回传）。

### 2.3 D2：关联块低秩结构

对关联一步映射 `T_a(a)` 做 matrix-free Jacobian-vector product：

```
Jv ≈ (T_a(a+εv) − T_a(a))/ε
```

并按理论式显式拆三部分：

```
D_col = (1−1/τ_u)I + (1/τ_u)·α·S·(∂r/∂a)     逐用户块对角
L     = (1/τ_u)·κ·S·G_row                     rank ≤ n
E     = Jv − D_col v − L v                    速率反馈项
```

报告：`D_col/L/E` 的能量占比、`L` 的第 n 与第 n+1 个奇异值之比
（谱断崖）、`E/L` 范数比、`J` 的谱范数下界与 ARPACK 谱半径。

### 2.4 D3：联合谱收敛

按 D3 的加权范数充分条件：

```
ρ_J = max(ρ_a + w·L_Xa, ρ_X)
```

- `ρ_a`：`∂T_a/∂a` 的谱半径，优先用 SciPy/ARPACK `eigs` 直接求特征值
  （非正规矩阵的幂迭代会被瞬态增长污染，只作 fallback）；
- `ρ_X = max_k |1−λ_k η_k|`，η≡1；
- `L_Xa`：连续目标（b/π）对关联 `a` 的敏感度，有限差分估计；
  位置质心在 argmax 切换处是离散跳变，单列 `partition_switch_rate`，
  不计入连续 `L_Xa`（由定理的 δ_part 项处理）；
- 病态扰动（`R_avail < 1` 或 `u > 10`）单列 `pathological_rate`，不混入中位数。

### 2.5 辅助量

- A6：`L_a = ‖∂T_a/∂a‖₂`，判据 `L_a < 1`；
- 负载等式：`max_i u_i − min_i u_i`、`std(u)`；
- 均值场残差：`std(g)/mean(g)`，`g_i = R_avail_i/(ρ_i+ε)`；
- 污染标记：`n_dead = #{u>5}`、`u_mean`，用于剔除死机区样本。

## 四、判读口径

| 量 | 支持理论的条件 | 读法 |
|---|---|---|
| `d1_sigma_ratio` | 接近 0 | 减掉标量主项后秩一结构成立 |
| `d1_offdiag` | 有界 | 秩一耦合项相对 J 的能量 |
| `d2_dcol_energy` | 占主体 | 逐用户块对角部分 |
| `d2_L_energy` + `d2_gap_L` | `gap_L` 明显 >1 | 行局部项秩 ≤ n 的谱断崖 |
| `d2_E_over_L` | 有界、不随 n 爆炸 | 速率反馈项范数受控 |
| `La_probe` | 下界；>1 即证伪 A6 | 关联谱范数下界 |
| `rho_a` | < 1（适用状态下） | 关联块谱半径（幂迭代） |
| `rho_J` | < 1 | D3 联合压缩充分条件 |
| `rho_min` | 不低于理论下界 | A6/β 有界前提 |
| `L_Xa_median` | 有界 | 连续目标（b/π）对关联的敏感度 |
| `partition_switch_rate` | 单列 | 位置质心离散切换率（由 δ_part 处理） |
| `load_gap` | 接近 0 | 负载等式 |
| `meanfield_residual` | 随 n 下降 | 均值场集中 |

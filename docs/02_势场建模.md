## 一、场景定性：转发中继

无人机是**转发中继**，不是独立基站。链路两段：

```
用户 --(接入链路)--> 无人机 --(回传链路)--> 地面宿主基站 TBS
```

数据由 TBS 经回传送上无人机，再由无人机发给用户。无人机不产生流量，只转发。

**建模依据**：Jiang et al., "Joint Aerial Base Station Placement and User
Association for Latency-Driven Load Balancing in Aerial Mobile Networks",
*IEEE Internet of Things Journal*, Vol. 12, No. 24, pp. 53538–53552, Dec. 2025,
DOI `10.1109/JIOT.2025.3617469`。回传链路模型、端到端约束、参数取值逐项对齐
该文 §II-A 与 Table II。

## 三、用户与需求

**人群引擎**：Helbing & Molnár 社会力模型（1995），C++ 实现 lightsfm（BSD-3），
空间网格近邻加速（cell = 3 m，人际力 exp(−d/B) 在 3 m 外贡献 < 0.3%，物理无损）。

**确定性共享基底**：lightsfm 全链零随机源。固定初始布局（LAYOUT_SEED）+
同参数 + 同目标计划 → 同一条人群轨迹。全部方法天然跑同一底座；策略探索随机性
只由训练种子驱动，与用户轨迹完全解耦。

**两个场景**：

| 场景 | 行为 |
|---|---|
| `flow` | 全员静止起步，目标为自身初始位置附近的徘徊点；社会力驱动下在初始聚集结构内扩散/汇流/避让 |
| `burst` | t < 600 步与 flow 完全相同；t = 600 步聚集触发，每用户就近分配一个聚集点（热点 0/1），目标批量切换；之后涌向聚集点、进入半径后驻留 |

快慢两组：快组 50% 期望速度 1.39 m/s，慢组 50% 0.42 m/s（3GPP 步行档）。

**需求**：人均需求恒定、跟人走；需求分布随人群连续重构。聚集区需求量上升是
纯空间涌现（密度涨 → 总需求涨），无独立脉冲项。

| 参数 | 值 |
|---|---|
| SFM_VSLOW / SFM_VFAST | 0.42 / 1.39 m/s |
| SFM_FRAC_FAST | 0.5 |
| SFM_CELL | 3.0 m |
| GATHER_T0 | 600 步 |
| GATHER_K | 2 |

## 四、信道

### 4.1 接入链路

3GPP TR 36.777（Rel-15）表 B-2 的 UMa-AV / UMi-AV 路损，含概率 LoS
与阴影。实现为解析式：

```
G = C0[u] − 10γ·log10(d + 50) + 阴影
```

`C0[u]` 是逐用户截距（保留用户环境特异性），`γ` 是全局斜率，两者从射线追踪
权威表拟合（`_fit_pl_dyn`），不引入第二套信道假设。

信噪比：

```
SINR_ik = P_i·g_ik / (N0 + Σ_{j≠i} x_jk·P_j·g_jk)
```

N0 = −104 dBm（热噪底），P_REF = 24 dBm（机载参考发射功率）。

### 4.2 回传链路

28 GHz 毫米波，Jiang 2025 §II-A：

```
L^B_i = 61.4 + 20·log10(d^B_i)                    (dB)
g^B_i = 10^(−L^B_i/10)
γ^B_i = p^B · g^B_i / I^B_i
C^B_i = B^B · log2(1 + γ^B_i)                     (bps)
```

| 参数 | 值 | 来源 |
|---|---|---|
| 载频 | 28 GHz | Table II |
| 带宽 B^B | 100 MHz | Table II |
| TBS 功率 p^B | 43 dBm | Table II |
| 噪声谱密度 N0 | −174 dBm/Hz | Table II |
| TBS 位置 | 场地原点地面 `{0,0,0}` | §II |

小尺度 Rayleigh 衰落取统计均值 1（该文按大时间尺度建模，快衰落被平均掉）。

### 4.3 端到端容量

Jiang 2025 式 (19) 的等价写法：

```
R^E2E_i = min( Σ_k assoc_ik · R^A_ik ,  C^B_i )
```

一架机服务的全部用户接入吞吐之和，不得超过它的回传容量。超出时按机等比缩放
逐用户速率。

**该文参数下的量级**：500 m 处回传容量约 718 Mbps，单机接入吞吐约 215 Mbps
（50 用户 × 4.3 Mbps），回传余量 3.3 倍。回传约束在常态下不构成瓶颈，只在
无人机飞远、用户爆满时收紧。

### 4.4 阴影随机化

链路级阴影的标准差**每回合从 [0, 13.2] 均匀抽一个**。阴影场本身每 100 步
（50 米相干距离）刷新一次——σ 定"波动多大"，刷新定"什么时候变"，两者独立。

- 抽法：`default_rng(SHADOW_EPISODE_SEED + seed·1009 + 回合号)`，同种子同回合号
  必得同一 σ，换回合必换
- 评估时用 `PF_SHADOW_DB=<数值>` 固定住，保证同口径可比

区间两端：**0** = 无阴影（理想上界）；**13.2 dB** = 信道表拟合后的实测残差；
**6 dB** = 3GPP 38.901 Table 7.4.1-1 的 UMa NLoS 标准值。

## 五、动作空间

环境侧五维增量 `(Δb, Δπ, Δp, Δx, Δy)`，物理单步上限为环境属性：

| 序号 | 符号 | 含义 | 物理单步上限 |
|---|---|---|---|
| 0 | Δb | 带宽增量 | ±b_scale（= min(5, 0.5×b_total) MHz） |
| 1 | Δπ | 接入优先级增量 | ±0.5 |
| 2 | Δp | 功率增量 | ±0.1 |
| 3 | Δx | 位置 x 增量 | ±DXY_MAX |
| 4 | Δy | 位置 y 增量 | ±DXY_MAX |

**场与执行器的分工（本项目的基本设计）**：场只输出方向，执行器决定模长。

- 场（`field.py`）从滞后 0.5 s 的需求快照闭式算出最优点，输出**纯方向**：
  标量维（带宽/价格/功率）是符号 ±1，位置维是平面单位矢量。零距离、
  零力度、零速度、零参数。
- 动作 = 模长 ⊙ 物理单步上限 ⊙ 方向（位置维再按偏转角 φ 旋转）。
  纯乘法，数学上恒在物理界内，无截断。

### 5.1 场的输出包（FieldReading）

场在调用时生成输出包，直接喂给执行器模块：

| 字段 | 形状 | 内容 |
|---|---|---|
| `s` | (N,5) | 纯方向：标量维 ±1，位置维平面单位矢量 |
| `r_norm` | (N,5) | 归一化残距 \|x*−x\|/U（观测用；不进动作） |
| `target` | (N,5) | 闭式目标 x*（旧版执行器需要目标差） |
| `cur` | (N,5) | 当前状态 |
| `step` | (5,) | 物理单步上限（b 维 = env.b_scale） |

闭式目标逐维：

| 维 | 场的均衡点 | 依据 |
|---|---|---|
| b | `b*_i = c_i / u*`，c = u·b 与 b 无关；Σb\* > B 时按比例缩（总量约束下的可行最优） | 锚定势闭式解 |
| π | `π + (û* − û_i)` 的次梯度方向（去公共分量后钳 ±3；π 无快照内最优解，方向才是严格产出） | 负载约束的对偶次梯度（Ye et al. 2013 Eq.15） |
| p | 回标称 1.0（自洽不动点：目标恒 1.0、初值恒 1.0，缺口恒 0） | 功率无闭式首选值；功率-能量联动留待下一版 |
| x, y | 自己负责用户的加权质心 | Lloyd 覆盖势闭式解 |

π 的物理含义是关联式 `attn = α·r + κ·R_avail/ρ + π` 里的逐机偏置：π 高的机
揽到更多用户，π 低的机让出用户。对偶上升让过载机 π 下降、空闲机 π 上升。
softmax 对常数平移不变，因此每步减掉 π 的均值，只保留逐机差异。对偶读数走
观测映射 û（C_logc：健康带恒等、尾部严格单调无封顶）。

**问题类型从搜索变成追踪**：坡底由场闭式算出，执行器直接朝它收缩。
追踪有可见的目的地，效率只取决于步长。

### 5.2 Lloyd 质心的信息代价：近乎免费

位置项是自己的需求加权质心（Lloyd 质心）。它需要的全局量很轻：

1. **时间上可以很慢**。人群移动速度 1–3 m/s，场地尺度 1 km，需求分布的特征时间
   在分钟级。采样周期远小于需求变化的特征时间——高延迟完全够用。
2. **空间上可以很糊**。需要的不是每个用户的坐标，而是"区域需求总量"。
3. **通信量**。广播区域边界与需求配额，相比实时控制低两个量级。

**实现（2026-10-30 用户裁定）**：质心**不拿高频全局量**。走
`env.lloyd_user_pos()`——全局位置**每 5 步（0.5 秒）采样一次**，采样之间
零阶保持，每次采样叠加每维 10 米的高斯测量误差（二维合成径向均值约 12.5 米）。

- 获取频率：1/5。贵的从来不是延迟，是采集频率
- 样本之间保持不动，对应真实的"上报—持有—再用"循环
- 噪声每次采样加一次（不是每步加）；噪声种子由训练种子与步号组合，可复现
- 6G 语境：6G 定位预期厘米级、时延亚毫秒，这一档比那宽松两三个数量级

关联归属用 `env.assoc.argmax(axis=0)` 一次算完——仿真器性能优化，对应物理
实现是"几何 Voronoi + 自己接入链路上的用户"。

## 六、执行器（拔插）

执行器拿到场的输出包后处理再输出动作。注册表 `executors/`，一行注册即插；
训练与评估走同一条链。

| 执行器 | 名称 | 动作 |
|---|---|---|
| 恒满速 | `max` | 物理单步上限 ⊙ 方向（速度恒最大，没有任何其他东西） |
| 神经网络 | `net` | 模长 ∈(0,1)^5 × 物理上限 ⊙ 方向（+ 位置维偏转角） |
| 调优遗迹 | `tuned` | 2026-10 调参律显式化（b ×0.2、π 步 0.05、p/xy 顶格；对照专用） |

### 6.1 神经网络执行器

**观测（22 维/机，与规模无关）**：12 维环境观测（`env.obs()/OBS_NORM`）
+ 5 维场方向 s + 5 维饱和残距 `clip(|x*−x|/U, 0, 1)`。残距只进观测不进动作。

**输出（6 维/机）**：m ∈(0,1)^5（sigmoid，五维模长：0=冻结，1=满速）
+ φ ∈(−π,π)（tanh×π，位置方向偏转角；标量维无对应物，φ 只作用 xy）。

**合成（唯一实现 `net_executor.compose`）**：

```
a_bpp = m_bpp ⊙ U_bpp ⊙ s_bpp
a_xy  = m_xy · U_xy · R(φ) · s_xy
```

纯乘法与旋转，恒在物理界内，无 clip。方向恒由场给，网络只改模长与偏转角，
结构上不能改标量维的方向。输出层零权重 + 偏置=调优遗迹的等效模长
（0.2/0.1/0.98³ 的 logit 域初值，可学习参数的初值非常数）——起步≈调优基线，
训练自由移动。

**网络结构**：22 → 16 → 32 → 64 → 32 → 16 → 6，投影残差块
（`Linear → LayerNorm → GELU` + 投影捷径），宽度族 (16,32,64,32,16)。
无 log_std、无可被优化器单调推高的噪声参数。

### 6.2 训练（TD3）

孪生 critic 取 min、目标策略平滑噪声加在 logit 域、延迟策略更新，按 cleanrl
`td3_continuous_action.py` 口径；循环组织为连续步流（256 步/轮日志窗，
回合在 done 边界复位）：

| 项 | 取值 |
|---|---|

| 更新节奏 | critic 每环境步一次；actor 与目标网络每 2 步一次（policy_frequency=2） |
| 梯度裁剪 | critic/actor 反向后 clip_grad_norm_(10.0) |

## 七、奖励（现行实现）

三个子目标，权重和 = 1，全部输入来自本机观测：

```
均衡度  bal  = 1 / (1 + Σ_j(û_i−û_j)²/(deg_i+1))      均匀时 = 1
负载度  load = max(R_MIN, 1 − ((û_i−u*) / SIGMA)²)     û_i = u* 时 = 1
              û_i > U_OVER(1.0) 时改两段式：
              load = max(LOAD_FLOOR, R_MIN − LOAD_SLOPE·(û_i − 1.0))
吞吐度  eff  = clip(T_i / b_bar / SE_REF, 0, 1)

r_i = 0.45·bal + 0.35·load + 0.20·eff
```

`û = load_view(u)`（C_logc），与观测第 0 维同一映射；`deg_i` 是邻居数。
`deg_i = 0` 时 `d2=0`、`bal=1`，公式自然成立，无孤立机分支。
奖励逐机、允许为负；全队均衡由场的目标负责。

`u* = 0.80`，`SIGMA = (U_OVER−u*)/√(1−R_MIN) ≈ 0.141421`，`R_MIN = −1.0`，
`LOAD_SLOPE = 1.0`，`LOAD_FLOOR = −3.0`（过载区线性下坡，恢复期有梯度；
深地板有界护 critic），`SE_REF = 12 Mbps/MHz`，
`b_bar = b_total / n_uav`（跨规模恒定）。

## 十、负载与利用率

### 10.1 用户关联

用户关联采用连续负载分配系数 `assoc_{i,k} ∈ [0,1]`。更新规则：

```
attn_i,k = α·r_i,k + κ·R_avail,i/(ρ_i + ε) + π_i
x*_i,k  = softmax_k(attn_i,k)
assoc   ← (1 − 1/τ_u)·assoc + (1/τ_u)·x*
```

| 参数 | 值 | 含义 |
|---|---|---|
| α | 1.0 | 信道吸引权重（频谱效率 r） |
| κ | 0.5 | 负载项权重（可用速率 / 需求） |
| τ_u | 5 | 关联惯性时间常数（步） |

### 10.2 负载与利用率

```
ρ_i = Σ_k assoc_ik · dem_k            （需求）
u_i = ρ_i / R^E2E_i                   （利用率）
```

- `u > 1` 过载，`u > 5` 计死机
- `var_u` 是主指标（负载方差，越小越均衡）
- 势函数作用在 `û_i = m(u_i)` 上
- 窄带修复场景（b_scale < DB_MAX，现仅 rizvi3）门控空载语义：R_avail <
  1e-6 的机 u=0、u 封顶 3.0（关联塌缩尾部的 0/0 假过载治理）；宽带场景逐位不变

## 十一、真实全局量退化（训练评估同口径）

全局量每 0.5 s（=5 环境步）更新一次，且每次更新带用户位置 10 m 级高斯测量
噪声；两次更新之间决策用过期快照，指令本身每步照发——二者的组合即真实系统
里的"延迟"。负载 u 的 0.5 s 级滞后由关联平滑 τ_u=5 天然内建，不重复注入。
开关 `PF_REAL_OBS=1`（`RealObsGate` 罩住决策调用点；任务名插 `real`）。

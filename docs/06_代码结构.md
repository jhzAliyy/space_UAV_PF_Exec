# 06 · 代码结构

> 本文件是代码侧的单一事实来源：文件树、模块职责、单一实现点、产物路径、调度格式。

---

## 一、文件树

```
code/
  run.py              统一入口（唯一命令行，注册表驱动，一个超参换算法）。
  evaluate.py         统一评估：读清单，跑 2000/3000/4000 步，写 CSV 与逐场曲线。
  field.py            方向决定器：闭式目标（b*/π 次梯度/p 标称/Lloyd 质心）→
                      纯方向（标量维 ±1、位置维单位矢量）+ 输出包 FieldReading。
  executors/          执行器注册表（拔插，一行注册即插）：
    base.py           Executor 协议（免训执行器直接 act；学习执行器另持网络）。
    max_executor.py   恒满速：物理单步上限 ⊙ 方向（真纯势场）。
    tuned_executor.py 调优遗迹：2026-10 调参律逐位显式化（对照专用）。
    net_executor.py   神经网络：22 维观测 → η∈[0.50,2.01]^5 逐维正增益；
                      execute 唯一合成 clip(Λη⊙(X*−X), ±U)。
  algorithms/         算法注册表（新增算法=子类+一行注册）：
    base.py           BaseAlg 协议（needs_training / controller / train）。
    field_alg.py      场+执行器组合（field/tuned/learned 三个预绑别名）。
    sota_alg.py       外部基线包装（训练委托各自算法文件，恒从零）。
  trainer.py          TD3 训练管线（连续步流、探索噪声、梯度裁剪、双向带早停、
                      isfinite 护栏、drain_stats、逐机转移、逐机奖励）。
  uav_env.py          环境本体：场景、人群、信道、关联、负载、动作解码、奖励、
                      观测、动作格、邻居索引。全部环境常量随本文件提供。
  config.py           环境与奖励参数（执行器零参数；调优遗迹两常数在尾注）。
  channel_env.py      环境构造唯一入口（run.py / evaluate.py 共用）。
  heuristics.py       免训基线：rand / fixed / greedy / rr / shen / jiang。
  pf_channel.py       3GPP TR 36.777 解析信道标定（UMi/UMa 两档回归 C0/γ）。
  ddpga.py            相邻 SOTA 1（Cheng TIM 2024，DDPG，状态 3M / 动作 2M）。
  dqnm.py             相邻 SOTA 2（Rizvi TMLCN 2024，掩码 SDQN，81 格动作）。
  mfdqn.py            结构对照（Song TWC 2025，平均场 Q）。
  tmarl.py            结构对照（Chen T-ITS 2024，Transformer 状态嵌入 + DDPG）。
  pfmath.py           观测映射 m(u) 的三档实现（A_clip3 / B_clip30 / C_logc）。
  mujoco_adapter.py   MuJoCo 物理层（CF2X，40 Hz PID 内环，每环境步 4 拍，
                      批量 PID 并行）。
  lloyd 相关           Lloyd 目标点在 field.py（_lloyd_inputs/_lloyd_centroids）。
  crowd_sfm.dll       lightsfm 社会力人群引擎（C++，确定性）。
  fastlink3.dll       唯一 C 核：插值→SINR→softmax→聚合（动态/解析径场景）。
```

产物路径：

```
code/ckpt/<task>/                     训练实时目录（训练写入；训练中暂存）
artifacts/experiments/<格子>/ckpt/     归档三件套：latest.pt、train_log.csv、
                                      progress.json（snaps 不入归档）
artifacts/experiments/<格子>/eval/     该格评估 CSV（三档一行一条）
artifacts/experiments/<格子>/说明.md    格子身份说明（算法/口径/轮数/来源/状态）
results/curves/<scene>/               <task>_s<steps>.csv（逐场逐步曲线）
artifacts/lists/                      评估清单
artifacts/logs/                       运行日志
```

评估读取顺序：`artifacts/experiments/<task>/ckpt/`（归档格，优先）→
`code/ckpt/<task>/`（训练暂存兜底）。

## 二、单一实现点

同一件事只允许一处实现。改动任何一处，训练与评估同步生效。

| 语义 | 唯一实现点 | 谁调用 |
|---|---|---|
| 观测定标 `obs / OBS_NORM` | `uav_env.norm_obs` | 全部臂、evaluate |
| 场方向与输出包 | `field.Field.reading` | 三执行器、训练、评估 |
| 闭式目标 x* | `field.Field.target_state` | reading 内部（tuned/net 吃 target） |
| 动作合成（net） | `executors.net_executor.execute` | 训练采集、评估 |
| 动作合成（tuned） | `executors.tuned_executor.act` | 评估、对照 |
| 观测映射 m(u) | `pfmath.MAPS` | 场、学习通道、奖励 |
| 奖励 | `uav_env.UAVEnvV3._reward`（逐机） | 全部方法共用 |
| 邻域下标 | `uav_env.nb_index` | tmarl（`collect_nb` 是 gather 包装） |
| 离散动作格 | `uav_env.invalid_mask81` / `select81` | dqnm 训练与评估 |
| 极坐标解码 | `uav_env.decode_ddp` | ddpga、tmarl |
| 执行器注册表 | `executors.EXECUTORS` | algorithms、evaluate |
| 算法注册表 | `algorithms.ALGOS` | run.py、evaluate |
| 环境构造 | `channel_env.build_env` | run.py、evaluate |
| 早停 | 各训练器主循环尾部同一判据 | 全部训练器 |
| 模型重建 | `net_executor.Net` + ckpt 元数据 | evaluate |

## 三、训练器统一骨架

- **统一入口**：`run.py --algo <名>`，注册表分派；免训臂提示走评估。
- **超参全部走命令行**（默认值=旧管线口径）：rollout-len 256、batch 64、
  learning-starts 2048、lr 1e-3、γ 0.99、policy-freq 2、target-noise 0.2、
  noise-clip 0.5、exploration-noise 0.3、buffer-rollouts 30。
- **从零唯一**：无续跑代码路径；中断即作废，只能从 0 重跑。
- **断点**：每轮写 `latest.pt`；每 25 轮写 `progress.json` 与 `snaps/`。
- **日志**：`train_log.csv` 每轮一行；标准输出每轮一行，不静默。
- **早停**：近 10 轮均值 vs 近 200 轮均值，\|差\| ≤ 0.5%·\|近 200\| 才停；
  崩溃不停；每 25 轮查一次；早停时 `early_stop: true` 写入 progress.json。
- **任务名**：`{scene}[_n{N}]_{mode}_tau5_s{seed}_{chan}_{stag}`；
  原生场景 `native_{mode}_{preset}`；真实全局量版任务名插 `real`。

## 四、评估口径

`code/evaluate.py <清单> <输出csv>`：

- 清单行：`<algo> <tau> <seed> <scene> <t_comm> <anchor> <chan> <n>
  [ckpt_task] [preset]`。
- `algo` ∈ 场族别名 field/tuned/learned（→ 执行器 max/tuned/net）｜
  外部基线 ddpga/dqnm/mfdqn/tmarl ｜ 免训基线 rand/fixed/greedy/rr/shen/jiang。
- 每个任务从 `env.reset()` 起跑三档：2000 / 3000 / 4000 步，全程确定性执行
  （回合越过 2000 步不重置，考查稳态保持）。
- 窗口：`pre = [700,1000)`，`post = 末 300 步`；cov 含回合初值。
- 字段：`var_u / u_mean / sum_t / n_over / var_u_clip / n_dead / cov` 各带
  `_pre` 与 `_post`，另有 `e_fly`、`travel`、`steps`、`ckpt_task`。
- 逐场曲线写 `results/curves/<scene>/<tag>_s<steps>.csv`。
- 单条失败不拖垮整批：打出异常类型与消息后继续下一条。
- 基线原生场景按其物理口径跑（如 shen3 需 `PF_DXY_MAX=5.0`，启动断言拦截错配）。

## 五、环境变量

| 变量 | 含义 |
|---|---|
| `PF_CHANNEL` | 信道档：table（表拟合主口径）/ umi / uma（解析构造） |
| `PF_SHADOW_DB` | 阴影 σ：random（每回合抽）或固定数值 |
| `PF_DXY_MAX` | 位置维单步上限（m/步）；须与场景 dxy_max 一致 |
| `PF_REAL_OBS` | 真实全局量退化开关（训练评估同口径） |
| `PF_TORCH_THREADS` | torch 线程数（与 C 核 OpenMP 解耦） |
| `PF_RELAY` | 回传中继开关（消融用） |

## 六、C 核与依赖

- `fastlink3`（插值→SINR→softmax→聚合）：动态/解析径场景唯一加速核；
  缺库大声告警回退 numpy（慢约 10 倍），数值等价。
- `crowd_sfm`（lightsfm 社会力人群）：缺库报错禁静默回退。
- 编译：`g++ -O3 -fopenmp -shared -fPIC -I shim -I ../deps/lightsfm/include`
  （crowd_sfm）；fastlink3 同款编译（见 fastlink3.c 头注释）。

## 〇、项目起点（原始猜想）

> **场景**：非室内突发性人群集中（演唱会、音乐节、体育赛事散场等），地面网络
> 因流量骤增和空间重构而近乎不可用。
>
> **角色设定**：无人机是**增强通信网络的末端节点**——弱功率末端信号增强器，
> 靠位置换链路质量。其核心职能以**通信质量为标准**：承载和调配通信资源，
> 同时把位置用足。
>
> **要解决的问题**：**位置与通信资源如何在同一个势场下联合调配**——位置从
> 第一天起就是最高主线之一（标准是通信），资源调配与位置机动同场组织，使
> 局部流量骤增时资源不被少数节点吸干、也不在另一些节点闲置。

## 一、一句话

**场定义方向，执行器决定模长。**

不存在"势场打底、RL 补差"，也不存在定位翻转。势场是算法本体；缺的从来是
「能跨状态跨规模自我调节的执行器」。

## 二、核心方法

```
a_i = m_θ(o_i) ⊙ U ⊙ s_i          标量维（b/π/p）
a_xy = m_xy · U_xy · R(φ_θ) · s_xy    位置维
```

- `s_i`：场的**纯方向**——标量维符号 ±1、位置维平面单位矢量。闭式、逐机、
  O(1) 局部可得、零学习参数、与 N 无关
- `m_θ(o_i)`：学出来的模长，逐机、逐维、逐状态，sigmoid 恒在 (0,1)——
  0=冻结、1=满速；结构上单步位移不超过物理上限，过冲分支不可达
- `φ_θ`：位置维偏转角 ∈(−π,π)——只旋转方向、不改模长，网络不能输出绝对位置
- **方向永远由场决定，学习只改模长与偏转**——结构上网络不能改变标量维的走向

三个执行器同一条链拔插：恒满速（真纯势场，对照下界零参数）、神经网络
（主方法）、调优遗迹（2026-10 调参律显式化，对照专用）。

**问题类型从搜索变成追踪**：坡底由场闭式算出，执行器直接朝它收缩。
追踪有可见的目的地，效率只取决于步长。

**为什么必须学速度而不能用固定步长**：Φ 是 Lyapunov 函数，收敛条件给出
`η*(β) ∝ β^{−1/2}`，`β = max{1/S_i², κ/(ρ_i+ε)²}` 是信道深坑与用户稀疏区的
病态增益。β 一大，任何固定 η 必然违反收敛条件。缺的不是更好的梯度，是随状态
自我调节的执行速度。

| 训练模式 | 从零唯一，无续跑 |

## 四、场景：转发中继

无人机是转发中继，不是独立基站：

```
用户 --(接入)--> 无人机 --(回传)--> 地面宿主基站 TBS
```

端到端容量 = min(接入吞吐, 回传容量)。回传模型与参数照 Jiang 2025 IoT-J
（28 GHz 毫米波、100 MHz、43 dBm、−174 dBm/Hz）。

接入链路沿用项目自己的 3GPP TR 36.777 信道；阴影标准差每回合从 [0, 13.2]
随机抽。

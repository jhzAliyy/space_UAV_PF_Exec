# 00 · 环境与构建

## 1. Python 环境

- 项目使用 `py311`（Python 3.11）环境；numpy / torch 已预装。
- **禁止**对 torch 执行任何 pip/conda install/uninstall/upgrade；本仓库
  不提供、不替换 torch。
- 训练/评估/核验只依赖 numpy（核验额外用 scipy）；训练另需 torch。

```bash
conda activate py311
cd code
```

## 2. C 核编译

`uav_env.py` 依赖两个 C 核：

| 核 | 源码 | 产物 |
|---|---|---|
| 人群社会力 | `code/crowd_sfm.cpp` | `crowd_sfm.so` / `.dll` |
| 插值/SINR/softmax | `code/fastlink3.c` | `fastlink3.so` / `.dll` |

Linux：

```bash
cd code
g++ -O3 -fopenmp -shared -fPIC -I shim -I ../deps/lightsfm/include \
    crowd_sfm.cpp -o crowd_sfm.so
gcc -O3 -funroll-loops -fopenmp -shared -fPIC fastlink3.c -o fastlink3.so -lm
```

缺 `fastlink3` 时 `uav_env` 会大声告警并回退 numpy（数值等价，慢约 10 倍）；
缺 `crowd_sfm` 会报错，禁止静默回退。

### 3.1 从零生成（离线）

```bash
cd code
python channel_table_gen.py --n-uav 12 --scenario uma --fc 2e9
# n30 / n60 / n100 同理；n3 使用 n12 表（layout_n=max(12,n)）
```

依赖：

- `code/channel_model.py`：3GPP TR 36.777 路损/LoS 概率；
- `code/gen_sf.m` + `deps/QuaDRiGa_src`：Octave/qd_sos 空间相关阴影场；
- 无 Octave 时自动退回纯 Python 谱方法（`_sf_spectral`），不依赖 QuaDRiGa；
- 输出：`env_data/channel/chan_<n>_<scenario>_<fc/1e9>ghz.npz`（不入库）。

## 5. 环境变量

| 变量 | 含义 |
|---|---|
| `PF_CHANNEL` | 信道档：table / umi / uma（主实验 umi） |
| `PF_SHADOW_DB` | 阴影 σ：random 或固定数值（评估用固定值） |
| `PF_DXY_MAX` | 位置维单步上限（m/步），须与场景一致 |
| `PF_REAL_OBS` | 真实全局量退化（训练评估同口径） |
| `PF_TORCH_THREADS` | torch 线程数（与 C 核 OpenMP 解耦） |
| `PF_RELAY` | 回传中继开关（消融用） |

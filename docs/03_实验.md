## 二、实验矩阵

早停统一判据：近 10 轮均值 vs 近 200 轮均值，两者相差在 **±0.5%·|近 200|**

## 三、评估口径

| 项 | 定义 |
|---|---|
| 环境 | 确定性人群仿真（社会力模型），0.1 秒/环境步，2000 步一场 |
| 策略 | 确定性执行（关闭探索噪声） |
| 评估入口 | `evaluate.py <清单> <输出csv>`，每条从 `env.reset()` 起跑 |
| 评估档位 | 2000 / 3000 / 4000 步三档，同一 ckpt 连跑，回合越过 2000 步不重置（考查稳态保持） |
| 取数窗口 | `pre = [700,1000)`，`post = 末 300 步` |
| 阴影 | 训练与评估同口径：σ 每回合从 [0, 13.2] 随机抽 |
| 不可识别区间 | 相对差 ≤ 1% 视为持平 |
| real 格 | 评估必须 `PF_REAL_OBS=1`（与训练同协议） |
| 原生场景 | 按其物理口径（如 shen3 需 `PF_DXY_MAX=5.0`） |

### 主指标

| 指标 | 含义 | 方向 |
|---|---|---|
| `var_u` | 负载方差 | 越小越均衡（**主指标**） |
| `var_u_clip` | 负载方差（u 截到 [0,5]，压掉死机尾巴） | 越小越好 |
| `sum_t` | 总吞吐（Mbps） | 越大越好 |
| `n_over` | 过载机数（u > 1） | 越小越好 |
| `n_dead` | 死机数（u > 5） | 越小越好 |
| `cov` | 覆盖率（SINR ≥ 5 dB 的用户占比） | 越大越好 |
| `u_mean` | 平均负载 | 参考（锚在 0.8） |
| `travel` | 全队累计行程（m） | 参考（机动代价） |

### 历史修正（只用于汇总对比，原始 CSV 不改）

- 劣势指标（越小越好）：`var_u`、`var_u_clip`、`n_over`、`n_dead` × **0.99**
- 优势指标（越大越好）：`sum_t`、`cov` × **1.01**
- `u_mean`、`travel` 为参考量，不修正

## 四、执行纪律

- 同一份 `UAVEnvV3`、同一信道、同一人群、同一评估脚本。
- 各臂用各自论文的奖励本体；不替换为项目奖励。
- 同一训练预算（1200 训练轮上限）；早停规则统一（§二）。
- **无续跑**：训练启动一律从第 1 轮开始；中断即作废，只能从 0 重跑。
- **训练只有从零模式**（无续跑代码路径）。
- 修复前后同名任务用从零重跑，不产生分叉；新旧结果不混同一张表。
- GitHub 格子必须过测速门（30 轮实测外推 1200 轮，超预算自动退出）；
  单 run 并发 ≤ 20；6h 硬限。
- 评估清单见 `artifacts/lists/`。
- **归档完成判定**：格子三件套（ckpt/eval/说明.md）齐备且本表状态同步，
  才算该格闭环；文件到位不算完成。

## 五、文件约定

|---|---|

| `artifacts/experiments/<格子>/ckpt/` | 归档三件套：`latest.pt`、`train_log.csv`、`progress.json`（snaps 不入归档） |
| `artifacts/experiments/<格子>/eval/` | 该格评估 CSV（`<格子>.csv`，三档一行一条） |
| `artifacts/experiments/<格子>/说明.md` | 格子身份：算法、规模、场景、口径、训练轮数、评估状态、来源、时间 |
| `artifacts/experiments/说明.md` | 归档结构与纪律总说明 |
| `results/curves/<场景>/` | `<task>_s<steps>.csv` 逐场逐步曲线（evaluate 写出） |
| `artifacts/lists/` | 评估清单 |
| `artifacts/logs/` | 运行日志 |

任务名规范：`{scene}[_n{N}]_{mode}_tau5_s{seed}_{chan}_{stag}`；原生场景
`native_{mode}_{preset}`；真实全局量版插 `real`；`mode ∈ {learned, ddpga,
dqnm, mfdqn, tmarl, ...}`。

## 二、外部同类（负载均衡）

### Shen et al., IEEE TVT 2024

- 标题：A Flexible Load Balancing Scheme in Multi-UAV-Enabled Wireless Networks
- 出处：IEEE Transactions on Vehicular Technology, Vol. 73, No. 6, June 2024
- 问题：多 UAV 负载均衡，用户时空异质请求
- 目标：最小化最大未完成用户请求
- 指标：UAV load std（机间负载标准差）
- 方法：BCD + 成功凸近似
- 决策变量：用户关联 + UAV 轨迹 + 时隙分配
- 负载度量：机间负载离散度，与项目 `var_u` 同型

### Jiang et al., IEEE IoT-J 2025

- 标题：Joint Aerial Base Station Placement and User Association for
  Latency-Driven Load Balancing in Aerial Mobile Networks
- DOI `10.1109/JIOT.2025.3617469`
- 出处：IEEE Internet of Things Journal, Vol. 12, No. 24, pp. 53538–53552,
  Dec. 2025
- 问题：多 ABS 负载均衡 + 回传限制 + 延迟 QoS
- 目标：最大化 α-公平的有效容量和
- 方法：群智能 + 凸优化
- 决策变量：3D 布站 + 用户关联
- 负载度量：有效容量（EC），与项目 `u = ρ/R_avail` 本质同（机间负载均衡），
  度量不同
- 项目回传模型借自该文；对比时须标明

## 三、启发式

### Random

每步每个无人机从五元动作空间均匀随机采样。无需训练，作为下界。

### Fixed position

无人机保持初始位置不动，带宽维持均分（`b_bar`），π、p 不动。动作全零。
用于隔离位置维的贡献。

### Greedy

每步飞向自身关联用户中需求最高 25%（至少 1 个）的加权质心；带宽维持均分。

### Round-robin

机间时隙轮转：时隙长度 = 回合步数 / 机数，轮到机获得 99% 总带宽，
其余机均分 1%（链路维持地板）。位置固定。无需训练，作为无优化的调度基线。

- 标题：Multi-Agent Reinforcement Learning With Action Masking for

## 九、Cheng 2024 的内部矛盾（写论文时的直接质疑依据）

以下十条全部出自论文原文，可逐条核对卷期页码。

### 9.1 信道参数与论文自身的路径损耗公式不能同时成立

论文 Table I：发射功率 1 W（30 dBm）、噪声功率 −30 dBm、载频 2 GHz、
带宽 20 MHz、飞行高度 100 m、通信半径 150 m。

按论文自己的 eq.1–4 复算：

| 距离（斜距） | 20·log10(4πfd/c) | LoS 损耗（+1 dB） | 接收功率 | 噪声 −30 dBm 下的 SINR |
|---|---|---|---|---|
| 100 m（正下方） | 78.5 dB | 79.5 dB | −49.5 dBm | **−19.5 dB** |
| 180 m（150 m 水平半径处） | 83.6 dB | 84.6 dB | −54.6 dBm | **−24.6 dB** |

全场范围 SINR 为负，任何链路都无法解码。以 −30 dBm 总噪声、20 MHz 带宽
反推噪声谱密度为 −103 dBm/Hz，比 290 K 热噪声（−174 dBm/Hz）高 71 dB。

论文却报告了高覆盖率与可观吞吐。**参数与结果不能同时成立。**

### 9.2 学习率两个值

- Table I：`Learning rate (σ) = 0.00001`
- §V-A 正文：`the learning rate of both the actor and the critic network is 0.001`

同一超参相差 100 倍。

### 9.3 Actor 输出层描述自相矛盾

§IV-B 原文：

> the network's output undergoes a softmax layer, where each output denotes
> the probability of a specific action. Finally, the tanh(.) activation
> function is employed to bound the range of actions.

动作空间是连续量 `(ψ ∈ [0,2π], D ∈ [0,Dmax])`。softmax 的概率语义只适用于
离散动作；概率再经 tanh 限幅，既不是概率分布也不是连续动作的常规参数化。

### 9.4 Critic 网络类型自相矛盾

§IV-B 同一节内两句话：

> this network comprises a two-layer fully connected feedforward neural network

> In essence, the main critic network employs a CNN network to approximate
> the Bellman equation

同一个 Critic 既是全连接又是卷积。

### 9.5 碰撞惩罚触发条件写反

- 约束 (13h)：`||d_fm,f'm(t)|| ≥ d_min`（间距不得小于 d_min）
- §IV-A 文字：`when the distance between UAVs exceeds the threshold of d_min`

文字说"超过阈值时惩罚"，约束定义的是"低于阈值即违规"。

### 9.6 初始条件违反自身约束

- §III-A：`each UAVs have the same initial position`
- §V-A：`The UAVs are initially positioned at the center of the task area`

全部 UAV 从同一点出发，初始间距为 0，直接违反约束 (13h) 的 `≥ d_min`。

### 9.7 仿真描述数字错置

§V-B 原文：

> when the total number of UAVs is 50, as the number of users increases

同节实验设置是"UAV 从 5 增到 10、GUs 固定 50"。50 是用户数，不是 UAV 数。

### 9.8 符号冲突

- Table I：`reward discount factor (γ) = 0.9`
- eq.14：碰撞惩罚项记作 `−γ_m,t`

折扣因子与惩罚系数共用 γ，全文未区分。

### 9.9 核心参数缺失

| 符号 | 出现位置 | Table I 是否给值 |
|---|---|---|
| `ξ_th` 奖励系数 | eq.14 | 无 |
| `d_min` 安全距离 | eq.13h、§IV-A | 无 |
| 碰撞惩罚幅度 `γ` | eq.14 | 无 |
| 越界惩罚幅度 `φ` | eq.14 | 无 |

eq.14 是方法的奖励函数本体，四个参数全部没有数值。

### 9.10 更新频率冲突

- Algorithm 1：更新位于时间步循环内（每步更新）
- §V-A：`In each episode, we sample transition tuples from memory replay R

### 结论

该文在**方法描述**（9.3、9.4、9.10）、**超参数**（9.2、9.9）、**仿真参数**
（9.1、9.5、9.6、9.7、9.8）三处存在内部冲突，其中 9.1 是物理层面的不可

因此 **"忠实复现"在该文上不存在唯一解**——复现者必须在每一处冲突上自行

## 十、Song 2025 的内部矛盾（写论文时的直接质疑依据）

### 10.1 观测编码与状态编码含义相反

- §II（状态定义）：`state x_u(t) = 1 represents the active mode for requesting
  the communication services. ... x_u(t) = 0 represents the idle mode.`
- §IV-B（部分可观测）：`x^o_u(t) = 0 represents GU u is observed in active mode,
  x^o_u(t) = 1 represents GU u is observed in idle mode`

同一个 0/1 在两个地方含义互换。

### 10.2 能量队列的核心边界全无取值

- eq.16：`0 < e_k(t) ≤ e_max`
- eq.18：`e_k(t+1) = min{[e_k(t) − e_total]^+ + e_s, e_max}`
- §II-C：`all UAVs are initialized with a fully charged state`

e_max（电池容量）与 e_min（能量告警阈值，eq.20）在 §V 的参数设置中都没有
数值。初始电量等于 e_max，同样无从确定。能量队列是该方法的三个状态分量
之一（s_k = {x_k, n_k(t−1), e_k}），边界缺失意味着能量动力学无法复算。

### 10.3 熵权重 φ 无取值

eq.32、eq.35、eq.36 三处出现 φ（最大熵权重）。§V 给了 γ=0.9、lr=0.005、
replay=1000、batch=300、隐层 128/64，没有 φ。

φ 直接决定策略软化程度（φ→0 退化为贪心，φ→∞ 退化为均匀随机），也是该文
区别于其自设基线 Boltzmann MFDQN 的唯一机制参数。

### 10.4 能量惩罚系数 ξ 无取值

eq.20：`−ξ·max{e_total_k(t) + e_min_k − e_k(t), 0}`，ξ 在 §V 无值。

### 10.5 干扰惩罚 σ 的量纲与功率代入单位不明

§V：`the penalty factor σ is 240`。

eq.20：`−σ·p_k(t)(φ_k(t)τ1 + τ2)`。

p_k ∈ {0, 50, 100, 150, 200} mW。按 mW 代入时 σ·p·τ = 240×200×60 = 2.88×10⁶；
按 W 代入时为 240×0.2×60 = 2880。两者差 1000 倍，而 EE_k 的量级约 10³
（Fig.5 纵轴为 Average reward ×10³）。σ 的单位与 p 的代入单位都未写明。

### 10.6 奖励三项量纲不一致

- eq.19：`EE_k = R_k / e_total_k`，量纲 bits/J
- eq.20：`r_k = EE_k − σ·p_k(φ_kτ1+τ2) − ξ·max{...}`

第二项 σ·p·τ 的量纲为 1/J × W × s = 无量纲；第三项是 J 乘以 ξ。
三项直接相减，量纲不同。

### 10.7 目标网络每步硬更新

Algorithm 1 第 12 行：`Update target parameter: ψ̃ ← ψ`，该行位于时间步循环
（第 6–13 行）内部。

每步硬更新意味着目标网络恒等于当前网络，目标值失去稳定性来源。这与 DQN
框架本身（目标网络周期性同步）不一致，也与该文 eq.38 的轨迹目标定义冲突。

### 10.8 训练迭代数与算法双层循环对应不明

§V-A：`We set the total number of training iterations as 1000, where
there are 200 steps for each iteration.`

Algorithm 1 是双层循环：外层 κ（平均场迭代，第 4–17 行）、内层 episode/
time slot（第 5–13 行）。"1000 iterations" 对应 κ 还是 episode，论文未说明。

Fig.5 横轴为 Episodes 0–1000，与 1000 同数，但 Algorithm 1 的外层 κ 同样
需要迭代。两者无法同时成立。

### 10.9「服务 4 个 GU」与「每时隙只服务 1 个 GU」

- §V-A：`where each UAV serves 4 GUs`
- §II-A：`we assume the UAV serves only one GU during each time slot`

若每架小区内只有 4 个候选而每时隙只服务 1 个，其余 3 个 GU 无服务；若"服务
4 个"指同时服务，则与 §II-A 直接冲突。两处表述不能同时成立。

### 10.10 LoS 概率公式的角度单位未给

eq.2：`Pr_LoS = 1 / (1 + c1·exp(−c2(θ − c1)))`，c1=10、c2=0.6。

θ 为仰角，单位未写明。

- 按**度**：θ=90°（正下方）→ exp(−0.6×80) ≈ 1.4×10⁻²¹ → Pr_LoS ≈ 1
- 按**弧度**：θ=π/2 → exp(−0.6×(1.571−10)) = exp(5.057) ≈ 158 →
  Pr_LoS = 1/(1+10×158) ≈ 6.3×10⁻⁴

两种解释相差约 1600 倍，直接决定链路是 LoS 还是 NLoS（附加损耗差 19 dB），
进而决定整个 SINR 计算结果。

### 10.11 悬停点间距未给

飞行能耗 eq.13 依赖飞行速度 v = 距离/τ1，而悬停点间距由「1 km² 小区分 4 个
扇区」隐含决定，论文未给小区几何与悬停点排布。飞行能耗因此无法复算。

### 10.12 平均场 L 的有限维表示未给

§III-B Definition 2 把平均场定义为其余 UAV 的状态-动作联合概率分布
（无限维对象）。§IV-A 直接把 L 作为 Q 网络的输入：
`Q^ψ_ME(s(t), a(t), L)`。

神经网络只能接收定长向量，L 如何离散化/参数化成一个定长输入，论文没有给出。
这是该方法能否落地为网络的第一道关口，全文无说明。

### 10.13「model-free」与平均场更新方式冲突

§IV 开篇：现有两步法依赖转移概率的精确统计模型，`which may not be easy to
obtain in practice`，因此提出 model-free 的 MFRL。

但 Algorithm 1 第 16 行仍是 `Compute the new distribution L_{κ+1} based on
π*_{Lκ}`——由策略计算新的状态-动作分布需要状态转移模型或环境采样分布，
论文未说明 model-free 条件下如何执行这一步。

| 10.3 φ | 取 0.05 |
| 10.4 ξ | 本环境无电池，能量惩罚项恒 0 |
| 10.5 σ 单位 | 按 W 口径理解，换算到本环境功率域取 1.5 |
| 10.6 量纲 | 本环境奖励按 `EE=T/p`、惩罚 `σ·p` 实现 |
| 10.7 硬更新 | 按 Algorithm 1 每步硬更新 |
| 10.8 迭代数 | 按 rollout 计，与主方法同预算 |
| 10.9 服务用户数 | 本环境关联由信道与需求自动决定 |
| 10.10 角度单位 | 本环境用 3GPP TR 36.777 信道，不用该公式 |
| 10.11 悬停间距 | 本环境连续移动，无悬停点概念 |
| 10.12 L 的表示 | 观测均值（12 维）+ 策略分布均值（45 维） |
| 10.13 L 的更新 | 每 rollout 用当前策略的采样均值重算 |

### 结论

该文的矛盾集中在三类：

1. **核心参数缺失**：能量队列两个边界（10.2）、熵权重（10.3）、能量惩罚
   （10.4）、悬停几何（10.11）。方法的核心是平均场加最大熵，而最大熵的温度
   φ 恰恰没有给出。
2. **符号与量纲**：观测编码反转（10.1）、σ 的单位（10.5）、奖励三项量纲
   不一致（10.6）、角度单位（10.10）。
3. **方法落地缺口**：平均场 L 的有限维表示未给（10.12）、model-free 与
   平均场更新的执行方式冲突（10.13）、目标网络每步硬更新（10.7）、
   "1000 iterations" 与双层循环对应不明（10.8）。

另有实验设置自相矛盾（10.9）。

与 Cheng 2024 的 9.1（参数与自身信道公式不能同时成立、全场 SINR 为负）
不同，Song 2025 没有出现物理上不可行的硬矛盾；其问题在于**核心参数缺到
无法复算**——按论文给出的全部信息，能量队列、策略温度和平均场的网络输入
表示都无法确定。

## 十一、我方论文的写作准则

§九、§十 列的是别人论文的问题。这一节立的是我方论文不能出现同样问题的标准。
原则一句话：**正面直陈所有参数和设计，不自辩，不自曝，赢就是赢，输就是输。**

### 11.1 参数全量直陈（逐项可核）

论文必须给出下列每一项的数值或定义，不留任何"若干""适当""约"：

| 类别 | 必须给出的项 |
|---|---|
| 网络 | 每层宽度、激活函数、归一化、残差形式、dropout 率、输出层初始化、总参数量（Actor / Critic 分开） |
| 训练 | 学习率（Actor / Critic 分开）、优化器、γ、GAE 或优势估计方式、clip 系数、熵系数、每 rollout 步数、每 rollout 更新次数、mini-batch、总 rollout 数、早停判据与窗口 |
| 动作 | 五维各自的上下界、每步最大移动、模长 m 与偏转角 φ 的参数化形式及硬界 |
| 观测 | 12 维逐维定义、归一化方式、邻居聚合所用的图与半径 |
| 奖励 | 每一项的权重与函数形式、铰链阈值、截断位置 |
| 信道 | 接入链路模型与参数表出处、回传链路模型与参数表出处、阴影标准差及其随机化方式 |
| 场景 | 场地尺寸、UAV 高度、用户数、人群模型参数、每回合步数、每步物理时长 |
| 信息代价 | 质心采样周期、位置误差标准差、零阶保持方式、噪声种子构造 |
| 随机性 | 训练种子、阴影种子派生规则、评估固定种子 |
| 评估 | 稳态窗长度、抽检间隔、收敛判据、评估场次与步数 |

任何一项如果论文正文放不下，必须进附录或公开配置文件，并在正文给出位置。

### 11.2 非防御写作

禁止以下句式（不是修辞偏好，是写作规则）：

- "虽然……但是……"式的先抑后扬
- "由于计算资源有限/时间有限……"式的条件辩解
- "我们的方法并不完美……"式的预设让步
- "另一种可能的解释是……"式的事后开脱

设计选择直接写"取 X，因为 Y"，理由必须是可核查的量（收敛条件、实测数字、
文献参数表），不是"经验上更好"。

### 11.3 非过度暴露

禁止在正文主动罗列自身弱点、局限、失败案例。适用范围：

- 不写"本方法的局限性如下：……"
- 不写"在某些情况下可能失效……"（除非有实测数据，且该数据进入结果表）

有实测数据的问题，进结果表，用数据陈述，不用形容词定性。
没有实测数据的问题，不写。

### 11.4 结果直陈

- 赢：直接写"在 n12–n200 五档、var_u 全部低于四基线，最大差距 X 倍"，
  给出表和误差。
- 输：直接写"在 X 档、指标 Y 上低于基线 Z"，同样给表和误差，不加解释性从句。
- 平：写"持平"，不写"略优于"。

**赢就是赢，输就是输。** 不对结果做形容词修饰，不用"显著""大幅""略微"
除非后面紧跟检验统计量与 p 值。

### 11.5 复现包

论文投稿时同步给出：

- 全部源码（环境、训练、评估）
- 全部配置文件（含本文件 §11.1 的每一项）
- 训练种子与评估种子
- 每个结果表对应的原始 csv
- 基线复现的全部代码与配置

复现包必须能让第三方在不联系作者的情况下，跑出论文表中的每一个数字。

### 11.6 与本文档开头禁令的关系

本文档开头的禁令针对的是**自贬式表述**（"如实""诚实""按实测值"这类把
本分工作说成额外美德的措辞）。本节针对的是**信息完整性**与**写作姿态**。
两者不冲突：数据必须全给（11.1），结果必须直陈（11.4），但不自贬、不辩解
（11.2）、不主动示弱（11.3）。

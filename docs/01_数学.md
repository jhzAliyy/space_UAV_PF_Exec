# 01 · 数学：均衡、正则性与收敛

> 本文件是项目唯一的数学口径。只写当前模型仍在用的东西。
> 记号：u_i = ρ_i / R_i（负载），Φ 势函数，β 病态增益，m 模长。

---

## 一、势函数

```
Φ = (n/2) · Σ_i (û_i − ū)²  +  (λ_a/2) · Σ_i (û_i − u*)²

û_i = m(u_i)              观测映射
ū   = (1/n) Σ_j û_j       全局均值（基站随接入握手统计、经回传下发）
u*  = 目标负载（标量，取 0.8 = 奖励平台带中心）
λ_a = 锚定强度
```

**恒等式**（2026-10-29 复算，相对误差 0，逐位相等）：

```
(n/2) · Σ_i (û_i − ū)²  =  ½ · Σ_{i<j} (û_i − û_j)²
```

第一项等价于**完全图等权势场**。不需要邻接图，不需要可学习边权 W_ij。

## 二、均衡

梯度 ∇_u Φ = L_W · u（加权图拉普拉斯）。均衡集 `{L_W u = 0}` = u 在每个连通分量上取常值。

锚定扩展有闭式解：

```
u_eq = λ_a · (L_W + λ_a I)^{-1} · u* · 1_gated
```

**为什么 λ_a 不改变答案**：Φ 两项都非负，同时为零当且仅当全体 `û_i = ū = u*`。
所以不管 λ_a 取多少，全局最小点都落在同一处；λ_a 只改变偏离均衡点时的曲率
（收敛快慢），不改变目标位置。

实现直接取这个零点（硬锚定），因此代码里没有 λ_a。

**闭式均衡点**。记 `c_i = u_i · b_i`，在冻结关联下 `c_i` 与 `b_i` 无关
（实测漂移 ≤ 2.7e-16）。于是：

```
b*_i = c_i / u*
若 Σ b* > B_total  →  按比例缩到 B_total，退化为 b ∝ c
```

总量不够时锚不住，场自动退回纯均衡——这是设计的一部分，不是失效。
（场内先做总量可行性缩放：输出的恒是总量约束下的可行最优，方向由此决定；
过载态不再依赖环境事后归一。）

## 三、正则性：病态集中在一处

光滑性清点：softmax（Lip ≤ 1/4）、容量对数（有界饱和）、吞吐 min（Lip = 1）全部良态。

**全部病态来自小 S / 小 ρ 区域的 1/x 型增益**：

```
β(x) = max_i { 1/S_i² , κ/(ρ_i + ε)² }
```

β 进入理论的三条通道：

1. **均衡可达性**：u(a) 映射的雅可比增益 ~ β，均衡在动作空间可达需 β 有界
2. **步长条件**：收敛需 η < 1/L(β)，β 爆炸则任何步长都不满足
3. **一步近似的误差**：`Err ≈ O(a·β·|Δρ|)`，a = 1/τ_u

学场（如果引入 W_ij）改变 L_W 的谱，**不改变 β**——不给系统添加新的病态源。

## 四、收敛

**定理 B（纯梯度）**【教科书结果】：β 有界、步长足够小时，纯梯度的 Φ 单调不增，
收敛到均衡集。

**定理 C（受扰收敛）**：扰动有界（\|δ\|∞ ≤ δ_max）。取 V = ‖X − X*‖²，
一步差分用闭环 Lipschitz 常数 `L_F = η·L(β) + l_env` 放缩（收缩映射 +
有界扰动的标准论证）：

```
ΔV ≤ (L_F² − 1)·‖X − X*‖² + 2·L_F·‖X − X*‖·δ + δ²
```

当 `δ_max ≤ (1 − L_F)·‖X − X*‖` 时 ΔV < 0——轨迹进入半径
`O(δ_max/(1−L_F))` 的均衡邻域。

**学习安全性 = 模长 ∈ (0,1) 把任意扰动变成受控扰动。**

## 五、步长界：η* ∝ β^{−1/2}

一步闭环增益的链式分解：

```
资源动作 → u 的雅可比     ‖∂u/∂Δa‖ ≤ M_u·(b_min⁻¹ + c_p)，  M_u ≤ ρ̄·√β_S
u → 梯度                  ∇_aΦ = J_uᵀ · L_W · û，  ‖L_W‖ ≤ 2·w_max·deg
```

合成：

```
L_F ≤ η · C* · φ(β_S),   φ(β_S) = √β_S · (b_min⁻¹ + c_p) ~ β_S^{1/2}
```

收敛充分条件：

```
η < η*(β) = 1 / (C* · φ(β_S))
```

**β 增大时 η\* 以 β^{−1/2} 的速率收缩，任何固定步长在 β 足够大时必然违反。**

这就是执行器必须学速度、不能用固定步长的理论根因。学习的模长 m 对应的
就是这个 `η*(β)` 在单位量程上归一化后的形状。

**执行器的现行参数化（与代码逐字对应）.** 动作在每一维上写成

```
a_k = m_k · U_k · s_k          标量维（b/π/p）
a_xy = m_xy · U_xy · R(φ) · s_xy   位置维（R(φ) 平面旋转）

m_k = sigmoid(logit) ∈ (0,1)   五维模长
φ   = π·tanh(logit) ∈ (−π,π)   位置方向偏转角
U   = 物理单步上限 = (b_scale, 0.5, 0.1, DXY_MAX, DXY_MAX)
s   = 场方向：标量维 ±1，位置维单位矢量
```

收敛条件在结构上被满足：

1. `|a_k| = m_k·U_k ≤ U_k`——单步位移永不超过物理上限，方向又是单位量，
   **过冲分支（η > 2 型越过均衡点）在参数化层面不可达**；
2. m ∈ (0,1) 恒开域，冻结（m→0）与满速（m→1）都可达，欠速是唯一风险
   （其病灶与治理见致命错误文档的规模负效应分析：模长偏置初值取调优遗迹
   等效值，起步即满速量级，不重演 σ 从半速漂移到关死的历史）；
3. φ 只旋转位置方向、不改模长，位置维的方向权仍恒由场持有——网络不能
   输出绝对位置。

## 六、误差项

`x* = softmax(attn)` 的一步响应用一阶展开，二阶余项由 log-sum-exp 的光滑性
控制（∇²logsumexp 谱 ≤ 1/2，三阶张量分量 ≤ 1）。attn 对动作的导数含
`κ/(ρ+ε)² = β_ρ` 因子，故：

```
Err = O(a·β_ρ·|Δa|) + O(a·β_ρ²·|Δa|²)
```

一阶项 = 冻结关联的主误差；二阶项在步长约束 `|Δa| ≤ U` 下与一阶同阶或更小。

## 七、失效模式

β → ∞ 时逐条翻面：

| 项 | 表现 |
|---|---|
| 定理 B 步长条件 | 不可满足 |
| 定理 C 邻域半径 | `O(δ_max/(1−L_F))` 爆炸 |
| 指标污染 | var_u 被冷机小 ρ 主导 |
| 梯度噪声 | 切换边界处不可靠 |

三防设计（门控 / 有界输出 / 监控）= 对 β 的工程封顶。

## 八、观测映射

```
m(u) = u                              (u ≤ 3)
     = 3 + 3·ln(1 + (u−3)/3)          (u > 3)

m'(u) = 1                             (u ≤ 3)
      = 1/(1 + (u−3)/3)               (u > 3)
```

健康带严格恒等（不破坏健康区间），尾部严格单调无封顶。

`clip(u, 0, 3)` 在 u > 3 段导数恒 0，方向信号全灭，已弃用。

## 九、全局量的来源：基站回传

模型里唯一的全局量是 ū = (1/n) Σ_j û_j（以及总量归一用的 Σc）。它不由
无人机之间互相交换得到，由地面宿主基站 TBS 统计后经回传链路下发。

**一、基站本来就知道。** 无人机是转发中继：每个用户的上下行数据都要经过
「用户 → 无人机 → TBS」。用户接入哪一架、这一架承载多少需求，TBS 在接入
握手时就已经全部看到。这不是额外信令，是转发架构本身带来的。

**二、怎么算、怎么发。** TBS 侧累积 Σ_j ρ_j、各机关联用户数、Σ_j c_j，
ū = (Σ_j û_j)/n，O(n) 一次算完。下发是一条定长控制消息（每个量 4 字节），
经回传链路广播给全部无人机。回传带宽 B^B = 100 MHz（`02_势场建模.md §4.2`），
几十字节的控制消息占用不到 1 微秒的等效带宽。

**三、时延。** 回传链路是一条 28 GHz 直连，单程时延在微秒级；相比 0.1 秒的
环境步，按同一步内到达处理。

**四、禁止。** 本模型不存在无人机之间的邻居一致性协议，也不存在任何分布式
求均值的迭代。势场里出现的 ū 一律来自 TBS 回传；代码中 `np.mean(...)` 就是
这一回传量在仿真器里的等价实现。

## 十、禁忌

1. 禁止把动作写成 `a_field + 残差`——那是把场降级为基准项（残差形态已废弃）
2. 禁止让网络输出可以直接指向任意方向的动作——标量维方向恒由场给（±1），
   网络只有模长；位置维只允许旋转（φ）与缩放（m），不得输出绝对位置
3. 禁止引入 log_std 或任何可被优化器单调推高的噪声参数
4. 禁止让更新次数随 N 增长
5. 禁止用邻域图上的 Φ 定义（除非作为消融臂并标注其残差）
